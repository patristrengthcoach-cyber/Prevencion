# Protocolo Preventivo — Racing Club Ferrol · Cantera

Panel interactivo de prevención de lesiones para la cantera del Racing Club Ferrol. Temporada 26/27.

## Qué es

4 bloques anatómicos rotativos (Cadena Posterior y Rodilla · Core Lumbopélvico · Cadera y Cadena Anterior · Tobillo y Pie), diferenciados por categoría (Alevín, Infantil, Cadete, Juvenil) y por tipo de sesión (Mixto, Tensión, Duración). Estructura: Miofascial → Movilidad → Estabilidad → Activación específica, ~20 minutos, 3 días/semana.

## Cómo usarlo

Abre `index.html` en el navegador (o el enlace de GitHub Pages, si está activado). Filtra por categoría, bloque y tipo de sesión. Cada ejercicio se puede reordenar, editar (nombre, dosis, nota, enlace de vídeo) o quitar de la sesión.

## Guardado de datos

- Si se abre **dentro de Claude.ai**, los cambios se guardan en la nube y los ve todo el cuerpo técnico.
- Si se abre **fuera de Claude.ai** (como aquí, en GitHub Pages o en local), los cambios se guardan en el navegador de ese ordenador únicamente.
- Usa los botones **"Exportar copia de seguridad"** / **"Importar copia de seguridad"** para mover los datos entre ordenadores o hacer una copia de respaldo en `.json`.

## Actualizar el archivo

Para subir una versión nueva, ve a este repositorio en GitHub → sube el `index.html` actualizado (Add file → Upload files, sobrescribiendo el existente) → Commit changes. GitHub Pages se actualiza solo en un par de minutos.
